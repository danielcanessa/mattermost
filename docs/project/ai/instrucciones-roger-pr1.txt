  openspec/        Propuesta, diseño, tareas y reportes de verificación
                   de la mejora.  -> CONSERVARLO por ahora. Es evidencia
                   del uso de IA en el proceso. Si en la revisión se
                   prefiere que vaya en un PR aparte, se mueve después.

  api/v4/ y e2e-tests/
                   Documentación de la API y prueba end-to-end de la
                   mejora.  -> Conservarlos, son parte de la funcionalidad.

3a. Comandos.

    En PowerShell (Windows):

      git rm -r --cached .cursor lidr-specboot
      Add-Content -Path .git\info\exclude -Value ".cursor/","lidr-specboot/"
      git checkout origin/master -- AGENTS.md
      git mv user_stories.md user_stories.enhanced.md docs/project/

    En Git Bash, macOS o Linux:

      git rm -r --cached .cursor lidr-specboot
      printf '.cursor/\nlidr-specboot/\n' >> .git/info/exclude
      git checkout origin/master -- AGENTS.md
      git mv user_stories.md user_stories.enhanced.md docs/project/

    Notas:
    - "--cached" saca los archivos del repo pero te los deja en tu
      computadora.
    - .git/info/exclude evita volver a subirlos por accidente, sin
      tocar el .gitignore de Mattermost.
    - La carpeta docs/project/ ya existe después del paso 2.
